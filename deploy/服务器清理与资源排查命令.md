# 服务器清理与资源排查命令

> 适用场景：ZDMJ 线上服务器日常巡检、磁盘爆满排查、内存压力排查、Docker 缓存清理。
> 执行前建议先 `cd /opt/zdmj/zdmj`，并确认当前用户具备 sudo 权限。

## 1) 快速体检（先看全局）

```bash
# CPU / 负载 / 运行时间
uptime

# 内存总览（包含 swap）
free -h

# 磁盘使用率
df -h

# 当前目录体积
du -sh .

```

## 2) 磁盘占用排查（从大到小定位）

```bash
# 查看根目录下各目录体积（按需缩小范围）
sudo du -xh --max-depth=1 / | sort -h

# 查看 /var 下大目录（Docker 日志常在这里）
sudo du -xh --max-depth=1 /var | sort -h

# 查看 /opt 下大目录
sudo du -xh --max-depth=2 /opt | sort -h

# 查找大于 500MB 的文件
sudo find / -xdev -type f -size +500M 2>/dev/null

```

## 3) 内存占用排查（进程级）

```bash
# 实时查看（推荐）
top

# 按内存排序展示前 20 个进程
ps aux --sort=-%mem | head -n 20

# 按 CPU 排序展示前 20 个进程
ps aux --sort=-%cpu | head -n 20

# 内核内存信息（排查内存回收压力）
cat /proc/meminfo | head -n 20
```

## 4) Docker 占用排查与清理

```bash
# Docker 总占用概览（镜像/容器/卷/构建缓存）
docker system df

# 查看更详细的占用明细
docker system df -v

# 查看构建缓存占用（若支持 buildx）
docker buildx du --verbose
```

### 安全清理（推荐先从这里开始）

```bash
# 删除悬空镜像（dangling images）
docker image prune -f

# 删除未使用容器
docker container prune -f

# 删除未使用网络
docker network prune -f

# 删除构建缓存（仅清理 7 天前）
docker builder prune -af --filter "until=168h"
```

### 激进清理（谨慎执行）

```bash
# 删除所有未被容器使用的镜像 + 停止容器 + 网络 + 构建缓存
# 可能导致下次部署耗时变长（需要重新拉取/构建）
docker system prune -af

# 连同未使用 volume 一并删除（风险更高）
docker system prune -af --volumes
```

## 5) Docker 日志排查与清理

```bash
# 查看容器日志文件大小（json-file 驱动）
sudo du -sh /var/lib/docker/containers/*/*-json.log 2>/dev/null | sort -h | tail -n 20

# 查看后端最近日志
docker logs --tail 200 zdmj-backend

# 截断某个容器日志（示例：后端）
sudo truncate -s 0 /var/lib/docker/containers/$(docker inspect --format='{{.Id}}' zdmj-backend)/$(docker inspect --format='{{.Id}}' zdmj-backend)-json.log
```

> 建议在 `docker-compose.yml` 为服务配置日志轮转（`max-size`、`max-file`），避免日志无限增长。

## 6) Node / pnpm 缓存清理（前端构建机器）

```bash
# 查看 pnpm store 路径
pnpm store path

# 清理无引用包缓存
pnpm store prune

# 查看 npm 缓存目录
npm config get cache

# 清理 npm 缓存（谨慎）
npm cache clean --force
```

## 7) Git 仓库清理（部署目录）

```bash
cd /opt/zdmj/zdmj

# 查看 .git 占用
du -sh .git

# 清理无引用对象并压缩仓库
git gc --prune=now

# 再看占用变化
du -sh .git
```

## 8) 常用巡检组合（可直接复制）

```bash
echo "===== $(date '+%F %T') ====="
uptime
free -h
df -h
docker system df
ps aux --sort=-%mem | head -n 10
```

## 9) 建议的定期维护频率

- 每天：执行一次“快速体检”。
- 每周：执行一次 Docker 安全清理（尤其 `builder prune`）。
- 每周：执行一次 `pnpm store prune`（若前端在服务器构建）。
- 每月：执行一次 `git gc`，并检查大文件来源。
