# 毕业设计课题

## 课题名称

面向计算机类专业的智能化求职学习规划平台

## 课题简介

计算机类（计算机科学与技术、软件工程、人工智能等）学生求职时，存在以下问题：一是自我认知模糊、职业认知片面；二是专业选择缺乏自主性，对行业的了解多为碎片化信息，易受同龄人压力影响盲目跟风；三是现有生涯教育重简历撰写、面试技巧等表层技能，缺乏系统的自我认知引导，难以给出可执行的求职规划。在「十五五」数字经济与产业升级背景下，同质化校招岗位收缩、能力门槛抬高，上述问题更为突出。

本课题面向计算机类校招场景，构建智能化求职学习规划平台，最终输出职业生涯发展报告。平台以大语言模型生成岗位与学生能力画像，以向量检索增强岗位认知与答疑，并根据岗位方向、对基础要求与职业技能等维度完成可解释的人岗匹配；最终聚合画像与匹配结果，结构化生成含行动计划的职业生涯发展报告。

平台为 Web 应用：后端使用 Java 、Spring Boot 构建服务，前端采用 Vue  实现交互，数据层使用 PostgreSQL（含向量检索）、Redis和对象存储，大模型能力通过 Spring AI 接入。系统按模块划分简历、岗位、人岗匹配、知识库、会话与职业生涯报告等服务，为用户提供多角度的求职辅助。

学生使用本平台可以：拆解岗位的具体能力要求；分析自身就业能力并结合求职偏好完成人岗匹配；在此基础上获得职业生涯发展报告，明确求职行动计划，扬长避短、精准匹配。
